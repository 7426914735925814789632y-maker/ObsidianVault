---
意味: 段取り表（.yml）から呼び出され、UZUやXの情報を集めてObsidian用のMarkdownファイルを1枚組み立てる「実作業担当のロボット本体」
---

## 概要・トリガー
- **素人向けの役割（なぜ必要か）:** 「ページを組み立てる作業ロボット」。段取り表（`.yml`）だけでは「前回の番号を探してリンクを貼る」「UZUのサイトから画像URLを拾う」といった細かい作業ができないため、実際のファイル作成をこのPythonプログラムに任せている。
- **保管場所と理由:** `scripts/create_uzu_page.py`
  - どこに置いても動くが、`Mainストレージ` の中に置くとObsidianの普段のノート一覧や検索がプログラムで散らかってしまうため、裏方プログラム専用の `scripts/` フォルダに隔離して整理している。
- **呼び出しワード / 発火条件:** `create_uzu_page.yml` から標準入力（`/tmp/uzu_payload.json`）を受け取って実行
- **対象 / 連携先:** `Mainストレージ/山口晃央/FOS［山口晃央］/(ⅷⅰ)_👑-⑦/│マーダーミステリー/│UZU履歴/{4桁番号}：「{シナリオ名}」.md`
- **動作:** 対象フォルダ内の既存ファイル（`\d{4}：*.md`）から直前の番号を探して `前回：[[...]]` を組み立て、UZU・XのカードリンクとX埋め込みを含むMarkdownファイルを書き出す

## AIが陥りやすい罠・必須の制約事項（仕様の勘所）

「UZUのページは普通のブラウザ偽装だと空っぽ、Twitterbotになりすませ」
1. **SPAサイトからのOGP取得失敗＝**
  - `uzu-app.com` はSPA構成のため、通常のChrome等の `User-Agent` でアクセスするとタイトルが「ウズ」だけでサムネイル画像が空のHTMLが返ってくる。
  - **対策:** `uzu-app.com` を取得する際だけ `User-Agent` を `Twitterbot/1.0` に切り替えてOGPを取得し、それでも欠損した場合はGASから渡された `x_image_url`・`『シナリオ名』`・`https://www.uzu-app.com/favicon.ico` で補完する。

「`![]()` の埋め込み記法は転記で壊れやすい、文字列結合で守れ」
2. **Markdown埋め込み構文の意図しない変換＝**
  - コード内の `[{x_post_url}]` をチャットやエディタ経由でコピー・編集する際、`!()` が削られて `[https://x.com/...]` という通常のリンク表記に化けることがある。
  - **対策:** Pythonコード上では `"!" + "[](" + x_post_url + ")"` のように文字列結合で記述して変換を防ぐ。またXの埋め込みURLは過去ページと仕様を揃えるため `https://x.com/...` のまま維持する。

「同名ファイルがあったら上書き厳禁、手で書いたメモを消すな」
3. **既存ノートの上書き事故防止＝**
  - 同じ累計番号でワークフローが再実行された際、すでにObsidian上で手入力した振り返りメモや追記内容が上書きで消失するリスクがある。
  - **対策:** 出力先に同名ファイルがすでに存在する場合、`overwrite` フラグが明示されない限り `File already exists, skipping` を出してスキップする（作り直したい場合は事前にGitHub上で該当ファイルを削除してから実行する）。
