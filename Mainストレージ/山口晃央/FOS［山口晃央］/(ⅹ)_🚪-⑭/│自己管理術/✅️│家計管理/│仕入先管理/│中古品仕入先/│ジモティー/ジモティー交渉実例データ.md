# 💬 個人間取引 交渉実例データ（マニュアル準拠）

## Phase 1：初回コンタクトの実例（実績ベース）
**目的**：防犯上の重たい条件は伏せ、相手にとって「安心でき、フットワークの軽い優良な買い手」であることを伝えて交渉を成立させる。

```text
【ぜひ譲ってください】
こちら、まだ募集されておりますでしょうか？
ぜひ、お譲りいただきたくご連絡差し上げました。

下に、私の簡単な自己紹介を添付いたします。
・東京都在住（※取引場所までのアクセス：電車で〇〇分ほど）
・自営業・20代男性
・平日昼間は融通が利きますため、こちらから取りに伺いたいと思っております。
・即日対応可能
・不手際・失礼などありましたら申し訳ありません。お気づきのことやご要望がありましたら、何でも気軽にお伝えいただけますと幸いです。

お返事をお待ちしております。
どうぞよろしくお願いいたします。
```

## Phase 2：日時・場所の確定 ＆ 書面提示の実例

### パターンA：通常の売買（有償取引）の場合
```text
ご返信ありがとうございます！
それでは、【〇月〇日（〇）の〇〇:〇〇】にお伺いさせていただけますでしょうか。

向かうにあたり2点だけ確認させてください。
1. 具体的な待ち合わせ場所は、【〇〇駅】のどちらの出口（人通りの多いロータリー等）になりますでしょうか？
2. 犯罪への巻き込まれ防止および不正品・トラブル防止の客観的な証明として、あらかじめ私の住所・氏名・連絡先を記入した「売買契約書（2部：控えお渡し用含む）」を持参いたしますので、現地にて内容をご確認のうえ、残りの必要項目（お名前・ご住所・お電話番号・サイン等）をご記入いただく形でもよろしいでしょうか？

お支払いは当日現地にて現金【〇,〇〇〇円】をお渡しいたします。
上記で問題なければ、受け渡し予定者に設定いただけますと幸いです。
よろしくお願いいたします！
```

### パターンB：無料（0円）で譲り受ける場合
```text
ご返信ありがとうございます！
それでは、【〇月〇日（〇）の〇〇:〇〇】にお伺いさせていただけますでしょうか。

向かうにあたり3点だけ確認させてください。
1. 具体的な待ち合わせ場所は、【〇〇駅】のどちらの出口（人通りの多いロータリー等）になりますでしょうか？
2. 犯罪への巻き込まれ防止および不正品・トラブル防止の客観的な証明として、あらかじめ私の住所・氏名・連絡先を記入した「譲渡証明書（2部：控えお渡し用含む）」を持参いたしますので、現地にて内容をご確認のうえ、残りの必要項目（お名前・ご住所・お電話番号・サイン等）をご記入いただく形でもよろしいでしょうか？
3. 無料でのお譲りとのことですので、お礼としてささやかな返礼品をお持ちいたします。なお、当日は現地にて一度現品を確認させていただき、こちらの希望する状態・仕様に合致しているか見させていただいた上で頂戴できればと存じます。

上記で問題なければ、受け渡し予定者に設定いただけますと幸いです。
よろしくお願いいたします！
```

## Phase 3：取引前日〜移動前の実例（身分証照合 ＆ 写真2枚交換の予告）
**目的**：直前のタイミングで、法人取引と同等の「顔写真付き身分証の相互照合」と「合流前の写真2枚交換ルール」を設定する。

```text
日時と場所のご調整ありがとうございます。

当日の現地での手続きにつきまして、お互いの安全確認とスムーズな合流のため、以下の2点にて進めさせていただけますでしょうか。

1. 書面の記載内容に相違がないか確認するため、当日は双方とも「顔写真付き身分証明書（免許証やマイナンバーカード等）」を持参し、現地で相互照合させていただけますと幸いです。
2. 待ち合わせ場所に到着しましたら、合流前にチャット上で以下の写真を2枚ずつ交換させてください。
   ・私から送る2枚：①用意した契約書（または譲渡証明書）の写真 ／ ②到着駅（または乗り継ぎ駅）の看板を背景に入れた写真
   ・出品者様から送っていただく2枚：①商品に改めて問題がないことがわかる写真 ／ ②現地に持ち込んでいることがわかる写真
   お互いの写真が確認でき次第、目印となる服装をお伝えしてすぐに向かいます！

お手数をおかけしますが、よろしくお願いいたします。
```

## Phase 4：現地到着時の実例（順序厳守・服装は後出し）
**目的**：相手から視認されない位置（死角）から最終確認を行い、現物が現地にあることを確定させてから合流する。

### ① 到着直後に送るメッセージ（※服装は絶対に書かない）
```text
お世話になっております。
ただいま待ち合わせ場所付近に到着いたしました！

事前にお伝えした通り、用意した「書面」の写真と、「到着駅の看板」を入れた写真の2枚をお送りいたします。
お手数ですが、現地にお持ちいただいた「商品の最終確認写真」と「現地に持ち込んでいることがわかる写真」の2枚をお送りいただけますでしょうか？

お写真を確認でき次第、こちらの服装をお伝えしてすぐに向かいます！
```
*(※2枚の写真を添付して送信。相手を焦らせないよう制限時間は書かず、内部基準として10〜15分待つ)*

### ② 相手の2枚の写真を確認した後に送るメッセージ
```text
お写真ありがとうございます、確認いたしました！
それでは今から向かいます。

本日は【服装・靴・メガネ・持ち物などの特徴】で向かっております。
よろしくお願いいたします！
```

## Phase 5：異常検知時・辞退時の撤退実例

### ① 事前・合流前に危険を検知した場合（※送信直後に即ブロック）
```text
ご連絡ありがとうございます。
大変恐縮ですが、急な予定が入ってしまい時間が間に合わないため、本日の取引は見送らせていただきます。
直前のご連絡となり誠に申し訳ございません。
```

### ② 現地で現品確認後、所望の品ではなかった場合（無料・有償共通）
```text
本日はお時間を作っていただきありがとうございました。
拝見したところ、想定していた状態・仕様と少し異なっておりましたため、大変恐縮ですが今回は見送らせていただきます。
お持ちいただいたのに申し訳ございませんでした。
```
