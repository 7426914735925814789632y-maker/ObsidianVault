# 生活習慣トラッキング＆自動連携システム 全体計画

## 1. システム概要とアーキテクチャ

生活習慣（まずは「瞑想」から構築）の記録をハブとなるGoogleスプレッドシート「習慣Log」に集約し、Habiticaでのゲーミフィケーション（コイン獲得）、X（旧Twitter）への自動発信、GitHub経由でのObsidian（DFBノート）への自動記録を一気通貫で行うシステム。

```
[入力系]
 ├─ Gemini (DFBチャット / βスキル) ──(客観データ記録)──┐
 └─ NFCタグ / MacroDroid (将来量産) ──────────────────┼─> [ハブ: スプシ「習慣Log」]
                                                      │    ├─ シート1 (実績ログ)
[日次評価 (タスク達成率・心身の健康度)] ──────────────┘    ├─ 習慣マスタ
                                                           └─ 日次評価・スコア変換マスタ
                                                                │
      ┌─────────────────────────┬───────────────────────────────┴──────────────────┐
      ▼                         ▼                                                  ▼
[Habitica API]            [X (Twitter) API]                                  [GitHub API]
 ・習慣実行で＋評価         ・マスタ指定のアカウントへ投稿                      ・Obsidian Vaultへ追記
 ・毎日3:30に日次評価送信     (例: 瞑想 → こあ🐨)                              (データ部分 + DFB文章統合)
```

## 2. 確定した仕様・設計方針

1. **スプレッドシート一元管理（「習慣Log」）**
    
    - 既存の `シート1`（実績ログ）に連携ステータス列（`Habitica連携済` / `X投稿済` / `GitHub連携済`）を追加。
        
    - `習慣マスタ` シートで習慣ごとの設定（投稿先Xアカウント、投稿テンプレート、HabiticaタスクID、増減方向、将来用WebhookURL）を一括管理。
        
2. **入力とスキルの役割分担**
    
    - **当面の入力**: GeminiのDFBチャットからの手動報告をトリガーとする。NFCタグ（Webhook）は将来的な量産に備え、マスタにURL記載欄のみ用意。
        
    - **DFBアシスタントの分割**: 随想から主観的体験を記録する「αスキル」と、客観的データのみを記録する「βスキル」に分離（本システムは **βスキル** に所属）。
        
3. **Habitica連携と日次評価（4:00リセット対応）**
    
    - 習慣単体の実行記録に加え、1日の「タスク達成率」「心身の健康度」をスコア変換してHabiticaの習慣（＋/－）へ反映する。
        
    - 1日の区切り（4:00）の直前である **毎日 3:30** にGASの定時トリガーで自動送信する。
        
    - `日次評価・スコア変換マスタ` の閾値テーブルを書き換えるだけで、達成率に応じた得点率（＋/－のクリック回数）を柔軟に調整可能。
        

## 3. 実装フェーズと所要時間見積もり（合計：約6.5〜9.0時間）

### Phase 1：データベース基盤の構築【完了】

- **所要時間**: 1.0時間
    
- **内容**:
    
    - `習慣Log` スプレッドシートの `シート1` に連携済フラグ列を追加。
        
    - `習慣マスタ` シートの作成（瞑想の初期設定完了、他11習慣の予約枠作成）。
        
    - `日次評価・スコア変換マスタ` シートの作成（閾値ルール表と日次集計・自動判定数式の実装）。
        

### Phase 2：中核連携ロジック（GAS・Habitica/X API）の実装【現在地】

- **所要時間**: 2.0〜3.0時間
    
- **内容**:
    
    - Habitica側での習慣タスク作成（「瞑想」「タスク達成率」「心身の健康度」）およびタスクIDの取得・マスタ登録。
        
    - GASプロジェクトの作成とAPI認証情報（Habitica / X `こあ🐨`）の格納。
        
    - 新規記録検知時にHabiticaのスコアアップ＋X自動投稿を行う関数の実装。
        
    - 毎日3:30に起動し、日次評価の判定結果（＋/－ × 指定回数）をHabiticaへ送信する定時関数の実装。
        

### Phase 3：入力系（DFB βスキル）と出力系（GitHub / Obsidian）の接続

- **所要時間**: 2.0〜2.5時間
    
- **内容**:
    
    - DFBチャット（βスキル）から `習慣Log` へ客観データを書き込む連携フローの調整。
        
    - GASからGitHub APIを叩き、ObsidianのDFBノートへ習慣データ（およびDFB記録シートの文章部分）をMarkdown形式で自動追記する処理の実装。
        

### Phase 4：「瞑想」での開通テストと他習慣への横展開

- **所要時間**: 1.5〜2.5時間
    
- **内容**:
    
    - 瞑想の報告 → スプシ記録 → Habiticaコイン獲得 → X投稿 → Obsidian反映のエンドツーエンド検証。
        
    - 3:30定時トリガーによる日次評価送信の動作検証。
        
    - 残りの習慣（プール・ウォーキング・ジョギング・サイクリング・少林寺拳法・読書・ジャーナリング・壁カレンダー・筋トレ・ストレッチ・掃除）のマスタ有効化とXアカウント・Habiticaタスクの紐づけ。
        
    - （任意）NFCタグ量産時のWebhook URL発行とMacroDroid設定。
